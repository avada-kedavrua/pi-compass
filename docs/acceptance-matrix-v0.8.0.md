# Pi Compass V2 0.8.0 — Eight-question acceptance matrix

The original project standard is **minimum total cost to complete arbitrary Goals, without quality regression**. More Compass calls, forced DAGs, and blanket Subagent fanout are *not* acceptance conditions.

No `tools.subagent` call inside Code Mode and no second agent runner. The parent need not wait synchronously for the first parallel read-only wave. | Real RC6 Pi 1.4.0 + pi-subagents 0.83.1 confirmed actual child event traffic, two concurrent read-only children and a dependent wave. `code` nodes intentionally remain parent-owned. |
